## Paleta y tipografías (variables CSS)

Definidas en `css/variables.css`, tomadas del manual de marca de AMAC y del Figma.

| Variable | Valor | Uso |
|---|---|---|
| `--color-primario` | `#202945` | Encabezado, pie, botones, títulos y texto |
| `--color-acento` | `#ff815c` | Barra de ayuda, botones de acento |
| `--color-azul-claro` | `#cae4ef` | Tarjetas |
| `--color-durazno` | `#fddaad` | Avisos, resumen y estatus "En revisión" |
| `--color-texto-suave` | `#4a5168` | Texto secundario |

**Tipografías:** Libre Baskerville (títulos) y Work Sans (contenido). Texto base de `1.125rem` (18 px), todo en `rem` para que escale con el navegador.
